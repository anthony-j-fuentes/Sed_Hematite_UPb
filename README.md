# Sedimentary Hematite LA-ICP-MS Geochronology 
This repository is for the analysis and presentation of in situ hematite U-Pb dating applied to hematite from sedimentary rocks associated with the in review manuscript: 

Fuentes, A.J., Courtney-Davies, L.C., Flowers, R.M, Wieser, P., Gleeson, M., Adamson, M.N., Zhang, Y., Swanson-Hysell, N.L. (in review) Revealing detrital and authigenic hematite within sedimentary rocks through single grain U-Pb geochronology.
